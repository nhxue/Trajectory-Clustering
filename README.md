# SFO Trajectory Clustering
This project focuses on identifying and understanding aircraft patterns in vectored airspace, which is the airspace between an arrival route's initial approach fix (IAF) and final approach fix (FAF), which is variable depending on several factors. 
The data is extracted from the OpenSky Trino database, filtered, and then analyzed, with hundreds of trajectories being clustered. 
K-means and Density-Based Spatial Clustering of Applications with Noise, or (DBSCAN), were used as clustering algorithms.
